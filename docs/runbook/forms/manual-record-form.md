# 수기 기록 표준 양식 (장애 중 사용 — 인쇄해서 쓴다)

> 시스템이 열리지 않을 때 실물로 오간 일을 적는다. **한 건에 한 장**. 복구 후 [장애 운영 수칙](../incident-sop.md) §3에 따라 시스템에 옮긴다.

---

**장애 기록 번호**: ______ (날짜-순번, 예: 1005-01)  **작성자**: ______________  **작성 시각**: ________ 년 __ 월 __ 일 __ : __

## 1. 무엇이 있었나 (해당 칸에 ✔ 하나)

- [ ] **서류를 받았다 / 보냈다** (인증서, 성적서, 증명서, 계약서 등)
- [ ] **인증 진행이 있었다** (신청 제출, 보완요청 수신, 승인, 반려 등)
- [ ] **연락을 주고받았다** (대행사·기관·상대와 전화/메일/방문 — 요지가 필요한 것)
- [ ] **기타** (아래 "요지"에 자세히)

## 2. 필수 항목

| 항목 | 기재 |
|---|---|
| **실제 발생일** (서류를 받은/보낸 날, 통화한 날, 승인 통지를 받은 날) | ________ 년 __ 월 __ 일 |
| **대상** (제품명·SKU·인증 이름 — 시스템에서 찾을 수 있게) | |
| **종류** (서류라면: 인증서 / CFS / GMP / MSDS / 성적서 / 기타 ___) | |
| **상대방** (대행사·기관·거래처 이름, 담당자) | |
| **요지** (한두 문장 — 무엇을 받았고 무엇을 요청받았나) | |
| **다음에 해야 할 일과 기한** (없으면 "없음") | 할 일: ________ / 기한: ____ 년 __ 월 __ 일 |

## 3. 서류 정보 (서류를 받았거나 보낸 경우)

| 항목 | 기재 |
|---|---|
| 서류에 적힌 **발급일** | ________ 년 __ 월 __ 일 |
| 서류에 적힌 **유효기간(만료일)** (없으면 "없음") | ________ 년 __ 월 __ 일 |
| **파일명 / 보관 위치** (스캔·사진 파일) | 예: `장애-1005/CFS_거래처A.pdf` |
| 원본 실물 보관 위치 | |

|---|---|

## 5. 확인 (복구 후 채운다)

- [ ] 시스템에 입력함 — 입력자: ________ 입력일: ________ (시스템이 자동 기록하는 입력일과 일치)
- [ ] 관리자 검산 — 확인자: ________ 확인일: ________

## 시스템 입력 대응표

복구 후 입력할 때 양식 항목이 시스템의 어느 필드에 대응하는지. **실제 발생일은 과거 날짜로 그대로 넣는다**(미래 날짜만 안 된다).

| 양식 항목 | 시스템 화면 | 시스템 필드 |
|---|---|---|
| 서류 · 발급일 | 문서보관소 → 등록 | **발급일** |
| 서류 · 유효기간 | 문서보관소 → 등록 | **유효기간** (보존기한은 서류 종류 규칙에서 자동 산정) |
| 서류 · 파일 | 문서보관소 → 파일 업로드 | 파일 (같은 파일을 같은 소유에 다시 올리면 중복으로 거절된다) |
| 인증 진행 · 신청일 | 인증 → 상태 전이(신청제출) | **신청일** |
| 인증 진행 · 승인일·시작일·만료일·인증번호 | 인증 → 상태 전이(승인) | **승인일·시작일·만료일·인증번호** |
| 인증 진행 · 반려·중단 사유 | 인증 → 상태 전이 | **사유** (필수) |
| 연락 · 실제 발생일 | 인증 상세 → 통신 기록 | **오간 날** |
| 연락 · 요지 | 통신 기록 | **요지** |
| 다음 할 일 · 기한 | 통신 기록 | **다음 액션 · 기한** |
| (없음) 입력한 날 | — | 시스템이 **등록 시각으로 자동 기록**(=복구 후 입력일) |

> 전표·재고·정산 계열 양식은 해당 기능(Phase 3 이후)이 생길 때 이 표에 추가한다.
