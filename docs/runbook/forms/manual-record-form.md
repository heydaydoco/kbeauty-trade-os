## 시스템 입력 대응표

복구 후 입력할 때 양식 항목이 시스템의 어느 필드에 대응하는지. **실제 발생일은 과거 날짜로 그대로 넣는다.** (통신 기록의 오간 날은 미래 날짜가 거절된다. 다른 날짜 필드는 시스템이 미래를 검사하지 않으니 직접 확인한다.)

| 양식 항목 | 시스템 화면 | 시스템 필드 |
|---|---|---|
| 서류 · 발급일 | 문서보관소 → 등록 | **발급일** |
| 서류 · 유효기간 | 문서보관소 → 등록 | **유효기간 만료일** (보존기한은 서류 종류 규칙에서 자동 산정) |
| 서류 · 파일 | 문서보관소 → 파일 업로드 | 파일 (같은 파일을 같은 소유에 다시 올리면 중복으로 거절된다) |
| 인증 진행 · 신청일 | 인증 → 상태 전이(신청제출) | **신청일** |
| 인증 진행 · 승인일·시작일·만료일·인증번호 | 인증 → 상태 전이(승인) | **승인일·유효 시작일·만료일·인증번호** |
| 인증 진행 · 보완요청·반려·중단의 실제 발생일 | 인증 상세 → 통신 기록 | 전이 폼에는 실제 발생일 필드가 없다 → **오간 날**에 적고 **요지**에 "보완요청 수신/반려 통지" 등을 남긴다(상태 이력에는 복구일이 기록된다) |
| 인증 진행 · 반려·중단 사유 | 인증 → 상태 전이 | **사유** (필수) |
| 연락 · 실제 발생일 | 인증 상세 → 통신 기록 | **오간 날** |
| 연락 · 요지 | 통신 기록 | **요지** |
| 다음 할 일 · 기한 | 통신 기록 | **다음 액션 · 기한** |
| 전표 · 견적(QT) | 메뉴 **견적** → **견적 작성**(헤더·라인 저장 후 **발행**) | 수기 임시번호=**메모(`internal_note`)에 병기**(공식 번호는 신규 채번) / 실제 발생일=**증빙일(`doc_date`)** / 상대방=바이어 / 품목·수량·단가=라인 / 비고=메모 |
| 전표 · PI | 견적 상세 → **PI 만들기**(참조 생성 — 품목·단가를 다시 입력하지 않는다) | 수기 임시번호=`internal_note` 병기 / 실제 발생일=**증빙일(`doc_date`)** / 상대방·품목·수량·단가=견적에서 복사 / 비고=메모 |
| 전표 · 수주(SO) | 견적·PI 상세 → **SO 만들기**(참조 생성) 또는 메뉴 **주문 접수(인테이크)** | 수기 임시번호=`internal_note` 병기(바이어 PO번호는 별도 칸에 그대로) / 실제 발생일=**증빙일(`doc_date`)** / 상대방=바이어 / 품목·수량·단가=원천에서 복사 또는 라인 입력 / 비고=메모 |
| 전표 · 발주(PO) | 메뉴 **발주** → **발주 만들기**(미리보기 후 발행) | 수기 임시번호=`internal_note` 병기 / 실제 발생일=**증빙일(`doc_date`)** / 상대방=공급사 / 품목(SKU)·수량·단가=라인 / 비고=메모 |
| (없음) 입력한 날 | — | 시스템이 **등록 시각으로 자동 기록**(=복구 후 입력일) |

> **전표 4종(QT·PI·SO·PO) 입력 계약**: 증빙일(`doc_date`)에 **미래 날짜는 422**로 거절되고 **과거 날짜에는 하한이 없다**(몇 달 전 것도 그대로 입력). **입력일(`created_at`)은 시스템이 자동 기록**하며 입력 본문으로 넣을 수 없다. 공식 문서번호는 저장할 때 **새로 발급**된다.
> 재고·채권·정산 계열 양식은 해당 기능(S3-3 채권·Phase 4 재고)이 생길 때 이 표에 추가한다.
