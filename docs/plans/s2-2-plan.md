## 3. 상태머신 (판정 안건 ③ 승인 문면)

상태 11값(코드 고정 — ADR-11): NOT_STARTED(미착수) / PREPARING(서류준비) / SUBMITTED(신청제출) / IN_REVIEW(심사중) / SUPPLEMENTING(보완요청) / APPROVED(승인·유효) / EXPIRING(만료임박) / RENEWING(갱신중) / REJECTED(반려) / EXPIRED(만료) / SUSPENDED(중단).

설계 등뼈 둘: ① **만료=비종결 달력 파생 상태**(종결로 두면 만료일 오입력→자동 만료→탈출 전무의 불가역 고착. §5.2 "만료(사유 필수)"는 자동 기록 사유로 충족 — 조건 B). ② **갱신=직행 왕복**(재진입시키면 갱신 신청의 반려가 유효 인증을 REJECTED로 종결시키는 축 혼동 — 상태 축=기존 인증의 유효성, 갱신 절차 세부=태스크·comm_logs(S2-4)).

허용 전이 27방향(A→B=수단. 사람 전이=인증+관리자, 전이 전용 엔드포인트+부속 데이터 동반·같은 트랜잭션):
1. 미착수→서류준비 = 사람(착수 기록).
