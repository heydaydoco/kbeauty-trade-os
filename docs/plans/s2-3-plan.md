## 0-5. PR-3 구현 판단 — 자율 확정 기록 (2026-09-29 — 오너 자율 지시에 따라 웹 세션 판정 없이 권장안 확정, 사후 번복 가능)

1. **[자율 확정] 매트릭스의 행·열 범위** — 열=삭제되지 않은 **전 시장**(코드순), 행=삭제되지 않은 **전 SKU**(상태 무관 — 단종 SKU도 행으로 나오되 `status`를 싣는다), SKU 코드순 페이지(기본 50·최대 200). 필터는 `q`(코드·품명 부분 검색, 와일드카드 이스케이프)·`item_profile_id`·`kind`. 사유: 행을 조용히 빼면 "왜 이 SKU가 없나"가 생기고, 상태 필터는 사용자 요구 전에 발명하지 않는다(관찰 등재).
2. **[자율 확정] 기준일은 API로 노출하지 않는다** — 서비스 인자(`base_date`)는 테스트·관통 전용이다. 사유: 임의 날짜의 계산값을 화면이 오늘 것으로 오인하지 않게. 응답은 `as_of`(KST 기준일)를 싣는다.
3. **[자율 확정] 캘린더 조회 기간 상한 93일**(초과·역순=사용자 안내 422 `to` 필드) — 계획 문면(§2 안건 ⑥ (c) "보드 조회 1본 신설 가능")에 상한 수치가 없어 채운 값이다. 사유: 기간 무제한이면 "전체를 읽고 잘라 주는" 조회가 된다(§18.4). 한 달+앞뒤 여유가 들어가는 크기.
4. **[자율 확정] 카드·항목 클릭 = 딥링크** — 인증은 `/certifications?id=`(인증 화면이 목록 1쪽 밖의 인증도 **단건 조회로** 상세 패널을 연다 — 목록 필터·쪽 이동에 종속되지 않는다), 문서는 `/documents`(문서 화면에 단건 딥링크가 없어 목록으로 — 관찰 등재). 사유: 계획 문면 "카드 클릭=기존 상세 이동"의 구현 수단이 이 화면들엔 없었다.

7. **[자율 확정] 칸반·캘린더 상한과 잘림 고지** — 칸반 200장(서버 페이지 상한, 필터 없음)·캘린더 한 달 200건. 넘으면 총계와 함께 고지(관찰 등재 #3 이행). 상태·시장 필터는 계획 ⑥ "제외: 필터 고도화"대로 비포함.
