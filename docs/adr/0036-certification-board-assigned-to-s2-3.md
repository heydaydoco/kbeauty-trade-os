# ADR-0036: 인증 보드(칸반+캘린더)는 S2-3 산출물로 배정한다 (WBS v1.4)

- **상태**: 채택 (S2-2 계획 웹 세션 판정 2026-08-11 — 안건 ⑪)
- **날짜**: 2026-08-11
- **관련**: DESIGN.md §14 ④ / WBS v1.4 / s2-2-plan.md §0-1 ⑪ / ADR-0001·0012·0015(미배정 발견→배정 선례)

**맥락** — §14 ④ "인증 보드(칸반+캘린더)"가 WBS 어느 세션 산출물에도 배정돼 있지 않았다(S2-2 계획 보고 실측 — 영원히 안 만들어지는 구조, ADR-0001과 같은 상황). S2-2는 목록·상세 화면까지다.

**결정** — S2-3 산출물로 배정한다. WBS v1.4 갱신, DESIGN 본문은 수정하지 않는다(§14가 이미 요구하는 항목의 배정이므로 — ADR-0015 방식).

**근거** — 캘린더 축은 기일 엔진 UI 자체이고, 칸반 컬럼은 S2-2가 세우는 상태 11값이며, 매트릭스·알림센터와 화면 수요가 같은 세션에 모인다.

**기각한 대안** — S2-2 편성(기일 데이터 없이 캘린더가 빈 껍데기), S2-4 편성(대행 협업과 축이 다름 — 보드의 축은 상태·기일이다).

**되돌리기 비용** — 낮다. 배정 변경은 WBS 갱신+ADR로 언제든 가능하나, S2-3 계획 보고가 이 배정을 전제한다.
