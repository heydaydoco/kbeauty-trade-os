# ADR-0008: 원가·마진의 로그 마스킹 + 감사 채널 예외

- **상태**: 채택
- **날짜**: 2026-07-24
- **관련**: DESIGN.md §18.1, §10.1, §12.4

**맥락** — §18.1은 원가·마진 마스킹을 "API 응답 레벨"로만 명시한다. 조회 역할이 화면에서 못 보는 값이 로그에는 평문으로 남으면 그 통제가 우회된다.

**결정** — cost·margin·unit_cost·landed_cost 등의 키를 로그 마스킹 대상에 포함한다. 다만 §10.1 배부·§12.4 "재고자산=lot_costs×수량 검산" 진단이 막히지 않도록, 원가 상세가 필요한 경우는 짧은 보존기간 + 접근통제된 별도 감사 채널로 분리한다(전면 마스킹 아님).

**근거** — 화면 마스킹과 로그 마스킹이 갈리면 통제에 구멍이 생긴다. 반대로 전면 `<redacted:cost>`면 회계·정산 대사 오류를 로그로 진단할 수 없다.

**기각한 대안** — 로그는 마스킹하지 않음(통제 우회) / 원가 전면 마스킹(진단 불가).

**되돌리기 비용** — 낮음(마스킹 키 목록 조정). 단 감사 채널 설계는 S6(회계 인터페이스) 착수 시 함께 확정 — 그 전까지 부채.
