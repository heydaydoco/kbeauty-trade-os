# ADR-0035: 품목군 요건 세트는 교차 테이블로 연결한다 (부채 #15의 S2-1 몫 종결)

- **상태**: 채택 (S2-1 계획 웹 세션 판정 2026-08-07 — 안건 1 / ADR-0021 배정 이행)
- **날짜**: 2026-08-10
- **관련**: DESIGN.md §4.8 / ADR-0021(내용 3종 배정)·ADR-0028 ⑧(서류 세트 선례) / PROGRESS 부채 #15 / s2-1-plan.md §2-5·§3-2

**맥락** — item_profiles(S1-1 헤더)의 내용 3종 중 요건 세트가 S2-1 배정분이다(서류=S1-3 완료, 마일스톤=S3-2 잔존). 대상(requirement_templates)이 이번 세션에 섰다.

**결정** — `item_profile_requirement_templates`(품목군×요건 템플릿) 교차 테이블, 부분 유니크 쌍 — `item_profile_document_types`(S1-3 ⑧) 선례 구조 그대로(63자 상한 수기 축약 포함). §4.8 "신규 등록 시 자동 적용"은 적용 결과물(certifications)이 서는 **S2-2 계획 보고로 명시 이월**(ADR-0021 문면이 이미 예약).

**근거** — 선례 동형이 유지 비용을 최소화하고, 자동 적용을 지금 만들면 소비자 없는 동작이 된다(ADR-0021 규율 — 상세는 소비 세션이 재판정).

**기각한 대안** — 템플릿에 프로파일 FK 컬럼(한 템플릿이 여러 품목군에 속하는 실무와 불합치), 자동 적용 동시 구현(승인 밖·소비자 부재).

**되돌리기 비용** — 낮다. 연결 테이블 drop이 전부이나, S2-2가 이 세트를 소비하기 시작하면 자동 적용 설계와 한 몸이 된다.
