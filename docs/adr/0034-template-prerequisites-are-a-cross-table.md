# ADR-0034: 선행요건은 자기참조 교차 테이블이고, 순환은 서비스가 거부한다

- **상태**: 채택 (S2-1 계획 웹 세션 판정 2026-08-07 — 안건 1·조건 1)
- **날짜**: 2026-08-10
- **관련**: DESIGN.md §5.1("선행요건") / s2-1-plan.md §2-4·§0-1 ① / WBS S2-1

**맥락** — §5.1 문면 "선행요건"은 단복수를 못박지 않는다. 웹 세션 도메인 판정이 다중 선행의 실재(중국 비안=경내책임자+안전성 자료 선행, EU 통보=RP 선행)를 확정해 단수 self-FK 컬럼안을 물리쳤다.

**결정** — `template_prerequisites`(template_id, prerequisite_template_id) 교차 테이블 — 0·1·다수 전부 포용. 자기참조는 DB CHECK(`no_self_reference`), 쌍 중복은 부분 유니크(`WHERE deleted_at IS NULL`), **깊이 2 이상의 순환은 선행 추가 시점에 서비스가 그래프 탐색으로 거부**한다(422).

**근거** — 깊이 있는 그래프 제약은 DB CHECK로 표현할 수 없어 검증 층이 갈린다(깊이 1=DB, 깊이 2+=서비스). 순환을 등록 시점에 막아야 소비 세션(S2-2 태스크 순서·선행 미충족 표시)이 위상 정렬 가능한 그래프를 전제할 수 있다.

**기각한 대안** — 단수 self-FK 컬럼(다중 선행 실재로 부결 — 판정 문면), DB 트리거 순환 검사(§17 규율 밖 장치 추가 대비 이득 없음 — 서비스 검증+테스트로 충분).

**되돌리기 비용** — 낮다. 소비자가 아직 없어(S2-2 전) 테이블 drop이 전부이나, 다중 선행 데이터가 쌓인 뒤 단수 컬럼으로의 회귀는 데이터 손실 판정이 필요하다.
