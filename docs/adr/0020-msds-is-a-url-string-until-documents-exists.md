# ADR-0020: MSDS는 S1-1에서 URL 문자열, S1-3의 documents로 승격한다

- **상태**: 채택
- **날짜**: 2026-07-29
- **관련**: DESIGN.md §4.1(DG 속성)·§4.7(문서 보관소)·§7.7(DG 게이트)·ADR-11(승격 규율) / WBS.md S1-1·S1-3·S4-4

**맥락** — §4.1은 MSDS 링크를 S1-1의 DG 속성에 포함하지만, 문서의 실체인 `documents`(유효기간·해시·보존기한)는 §4.7이자 **S1-3** 산출물이다. 지금은 FK를 걸 대상 테이블이 없다.

**결정** — S1-1은 `skus.msds_url`(문자열) 하나만 둔다. **S1-3에서 `documents` 행으로 승격**하고 `msds_url`은 그때 제거한다(마이그레이션으로 이관). 유효본 여부를 판정하는 §7.7 DG 게이트는 Phase 4이므로, 그전까지 링크 문자열로 충분하다.

**근거** — ADR-11의 승격 규율("검색·집계·검증이 필요해진 필드는 정식 컬럼으로 승격")과 같은 형태다. 지금 필요한 것은 "어디에 있는지"뿐이고, "유효한지"는 유효기간·해시를 가진 `documents`가 생겨야 답할 수 있다. 승격 시점을 ADR에 못박지 않으면 임시 문자열은 반드시 영구 잔류한다 — S1-3에서 `documents`를 만들면서 "이미 링크가 있으니까"로 넘어가는 것이 정확히 그 경로다.

**기각한 대안** — ① 컬럼 자체를 S1-3까지 보류: WBS S1-1 산출물의 "DG 속성 전체"가 미충족이 되고, DG SKU를 등록할 수 있는데 MSDS만 못 적는 상태가 된다. ② S1-1에서 `documents`를 미리 만들기: §4.7의 폴리모픽 소유·보존기한·파기 잠금까지 딸려 오는데 소유자가 될 엔터티 대부분이 아직 없다.

**되돌리기 비용** — 낮다. 승격 마이그레이션 1건과 화면 필드 1개. 다만 승격을 안 하면 §7.7의 "MSDS 유효본 미첨부 차단"이 검증 불가 상태로 남는다.

**부채 등록** — PROGRESS.md 부채 목록에 "MSDS 문자열 → documents 승격(S1-3)"으로 기록한다.
