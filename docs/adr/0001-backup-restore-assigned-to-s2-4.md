# ADR-0001: 백업·복원 리허설을 S2-4 완료 기준으로 배정

- **상태**: 채택
- **날짜**: 2026-07-24
- **관련**: DESIGN.md §2(운영 품질)·§19 Phase 2·§20 H·§21 / WBS.md S2-4 / WBS v1.1

**맥락** — DESIGN.md §2가 "백업 = DB(pg_dump 일일)+파일 저장소(files/) 세트로 수행하고 복원 리허설도 세트로(주 1회)"를 요구하고 §20 H에도 "DB+파일 세트 복원 리허설"이 테스트 항목으로 있으나, WBS v1.0의 **어느 세션 산출물에도 백업이 배정돼 있지 않았다** — 영원히 안 만들어지는 구조였다.

**결정** — S2-4(Phase 2 마지막 세션) 산출물에 "pg_dump 일일 백업 스크립트 + files/ 세트 백업"을, DoD에 "DB·파일 세트 복원 리허설 1회 통과"를 추가한다.

**근거** — §19가 Phase 2를 "★ MVP: 여기서부터 실사용"으로 명시한다. 실사용이 시작되면 그 시점부터 소실 시 복구 불가능한 실데이터가 쌓이므로, Phase 2의 마지막 세션이 "백업 없이 실운영에 들어가는" 것을 막는 마지막 관문이다. §21의 "백업은 복원 리허설까지가 백업" 원칙에 따라 스크립트 존재가 아니라 **복원 성공**을 완료 기준으로 삼는다.

**기각한 대안** — ① S0-1에 배정: 지킬 데이터가 0바이트라 리허설이 공회전이고 인프라 세션을 비대하게 만든다. ② 부채로 기록 후 미배정 유지: §2·§20 H가 요구하는 항목을 "나중에"로 미루면 실사용 개시와 백업 부재가 겹치는 최악 구간이 생긴다.

**되돌리기 비용** — 낮음(WBS 문서 항목 이동). 단 **배정을 더 뒤로 미루는 방향의 되돌리기는 비용이 비대칭**이다 — 백업 없이 지나간 기간의 데이터는 사후에 복구할 방법이 없다.

**미해결 논점(영준이 확인 필요)** — 실데이터의 최초 유입은 Phase 2가 아니라 **S1.5(기존 엑셀 대장 이전)**다. S1.5~S2-3 4개 세션 구간은 실데이터가 있으나 백업이 없는 상태가 된다. 분할안: S1.5 DoD에 "pg_dump 수동 백업 1회 실행+파일 확인", S2-4 DoD에 "일일 자동화+복원 리허설 통과". 확정 시 본 ADR을 개정한다.
