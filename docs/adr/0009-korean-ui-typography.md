# ADR-0009: 한국어 UI 타이포 전역 기본값

- **상태**: 채택
- **날짜**: 2026-07-24
- **관련**: DESIGN.md §14

**맥락** — §14가 "break-keep 기본, 좁은 셀·협정명·국가명 nowrap, 숫자·기준값 가운데 정렬"을 요구한다. 첫 화면부터 전역 기본값으로 심어야 이후 세션이 제각각으로 흩어지지 않는다.

**결정** — 전역 CSS에 `word-break: keep-all` + `overflow-wrap: anywhere`. `.cell-nowrap`(협정명·국가명·좁은 셀), `.num`(숫자 가운데 + `tabular-nums`) 유틸. 금액도 §14 문면대로 가운데 정렬(`.num`)로 구현.

**근거** — 한국어는 어절 단위 줄바꿈이라야 읽히고, 긴 영문·숫자만 overflow-wrap이 받는다. 전역 기본값이 없으면 컴포넌트마다 달라진다.

**기각한 대안** — 컴포넌트별 개별 지정(흩어짐) / 금액 우측 정렬(자릿수 비교엔 유리하나 §14 문면 위반).

**되돌리기 비용** — 낮음. 단 후속 세션이 "금액은 우측 정렬"로 임의 변경하는 것은 금지 — 필요 시 DESIGN §14 갱신 + 이 ADR 개정으로만.
