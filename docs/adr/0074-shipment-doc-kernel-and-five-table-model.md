# ADR-0074: 선적을 전표 커널에 편입한다(DocKind `SHIPMENT`·접두어 `SH`) — 5표 모델·원천 FK 정확히 하나·수입 원가 비복사·상태 8값 활성 3엣지·실적/통관 생존 시 취소 차단

- **상태**: 자율 확정 — 사후 번복 가능 (S3-2 계획 2026-10-04 — 오너 지시 2026-09-29에 따라 판정 후보는 더 엄격한(fail-closed) 권장안으로 확정, ADR-0011 부기)
- **날짜**: 2026-10-04
- **관련**: DESIGN.md §7.1·§7.2·§7.5·§17.3·§17.5(S3-2 [M4] 보강) / WBS S3-2 / ADR-0051·0052·0053·0054·0024 / docs/plans/s3-2-plan.md · docs/plans/s3-2/design-integrated.md(§9 적대 검토 정정 우선) — sA §A1~A9, X-03·X-05, R-01·R-04·R-15·R-16 / 구현 PR-3a(M14)·PR-4a(M15 통관)

**맥락** — §7.5는 선적(Incoterms·환율 고정·구분 4종)과 부분 1:N을, §7.2는 선적 상태 열거(계획→출고지시→피킹→검수완료→출고→선적→종결/취소)를 정한다. 선적은 SO·PO의 후속이라 역순 취소·잔량·이력 불변·아웃박스 계약을 받아야 하는데, 커널 밖에 두면 이 계약을 다시 만들어야 하고 그 재구현이 곧 우회 표면이다. 수입선적은 원가를 가진 PO에서 온다(ADR-0024 PO 원가 9채널).

**결정** — ① `DocKind.SHIPMENT`(접두어 `SH`, 수출·수입 한 kind + `shipment_kind` 4값 EXPORT·IMPORT·CHANNEL_INBOUND·SAMPLE_FREE)로 커널에 편입하고 상수 dict 11종·FIELD_POLICY·사슬 레지스트리를 함께 등록한다. ② 테이블 5개: `shipments`·`shipment_lines`·`shipment_parties`·`shipment_status_log`(IMMUTABLE)·`customs_records`(신고 1:N 사실 기록 — 세율·과세가격·세액·HS 열 없음, **M15/PR-4a**). ③ **헤더 원천 FK 정확히 하나**(EXPORT ⇔ `so_id`, IMPORT ⇔ `po_id` — CHECK), 채널입고·샘플무상 행은 DB가 거부(값만 싣고 생성 경로 미개방), 다중 SO 합적 없음. ④ 통화·고정 환율·결제조건 4열·Incoterms 3열·거래 상대·SKU 품명은 원천 ORIGIN 사본(생성 본문에 필드 없음 — `extra="forbid"`), **`doc_date`는 생성 시 `today_kst()` 1회·이후 불변**. 수출 라인 금액 CHECK는 `quantity::numeric * unit_price_amount = line_amount`+무상 규약 승계, **수입 라인은 단가 NULL·금액 0**(원가 비복사). ⑤ 상태 8값, 활성 사람 엣지 3(PLANNED→RELEASE_ORDERED 전용 `release-order`·PLANNED/RELEASE_ORDERED→CANCELLED 사유 필수), PICKING~CLOSED 5값 RESERVED(S4-2), 라인 편집은 PLANNED만(`TRADE_DOCS.DOCUMENT.FROZEN`). ⑥ **ETD·BL_ISSUED·ETA 실적은 RELEASE_ORDERED에서만**(PLANNED = 422 `SHIPMENTS.MILESTONE.ACTUAL_BEFORE_RELEASE`), 그 실적이나 살아 있는 통관 기록이 있으면 선적 취소 409(`SHIPMENTS.SHIPMENT.ACTUAL_RECORDED`·`CUSTOMS_RECORD_ALIVE`). ⑦ 총수 핀 30/152/182(ADR-0075와 합산).

**근거** — 커널 편입이면 단일 전이 통로·이력 IMMUTABLE·총수 핀·역순 취소·채번(ADR-0054 "접두어는 멤버 추가만")을 그대로 받는다. 원천 FK를 하나로 조이면 사슬 판정·잔량·SO 수렴이 단순해지고, 열면 링크 표 이전이 필요하다. 실적 생존 취소 차단은 §20 A "후속 생존 시 선행 취소 차단"의 선적판이다(적대 R-01 — 차단 없으면 ETD 실적이 있는 선적을 취소해 SO 잔량이 복원되는 fail-open).

**기각한 대안** — 커널 밖 독립 상태 기계(계약 재구현·`record_transition` 보호 밖), 수출·수입 별도 kind(총수·dict 2배), 수입 접두어 `SI`(S3-3 Shipping Instruction과 충돌), 다중 SO 합적 링크 표(실수요 없음 — 부채), 통관 표를 M14에 선생성(쓰기 경로 없는 표 구간 — R-16), 실적 생존과 무관한 자유 취소.

**되돌리기 비용** — **높음**(DocKind 값이 상태이력·아웃박스에 저장 — 운영 데이터 이후 분리 불가에 가깝다. 3a·4a는 운영 실데이터 투입 전 병합 권장). 원천 FK 완화(합적 허용)도 높음. 실적 취소 가드 제거·채널입고 경로 개방은 낮음(가드·CHECK 1개).

**부기(2026-10-04 — S3-2 PR-3a 이행: 커널 편입·M14)** — ①·③·④·⑤·⑦을 구현했다. `DocKind.SHIPMENT`(접두어 `SH`)와 상수 dict 11종·`ShipmentStatus` 8값·`FIELD_POLICY`(shipments·shipment_lines)·`CHILD_LINKS`(SO→shipments·PO→shipments)·FK 허용목록을 첫 커밋 하나에 묶었다(R-23 ①). **M14 `acd34f28c11e`(down `394c76a7d2b7`)는 4표**(`shipments`·`shipment_lines`·`shipment_parties`·`shipment_status_log` — 마지막은 IMMUTABLE·`revoke_mutations`) — `customs_records`는 ② 그대로 M15/PR-4a(R-16). 헤더 CHECK `ck_shipments_kind_source`가 "원천 FK 정확히 하나 + EXPORT⇔`so_id`·IMPORT⇔`po_id`"라 채널입고·샘플무상 행은 DB가 거부한다(값은 `kind_valid`에만). **생성 경로는 수출(SO 참조)뿐**(수입 = PR-5a). 설계 침묵분은 더 엄격하게 DB에 걸었다(자율 확정): `import_has_no_amount`(수입 헤더 합계 0)·`source_terms_complete`(결제유형·Incoterms·환율 사본 NOT NULL)·`no_copy_lineage`(선적 복제 없음)·`planned_not_frozen`/`released_frozen`(동결 시각 ⇔ PLANNED 밖)·라인 `export_free_iff_zero_price`·당사자 `auto_role`(자동 스냅샷 행은 CONSIGNEE·SHIPPER만)·`name_en_clean`(공백·제어문자 금지). `doc_date`는 생성 시 `today_kst()` 1회(ORIGIN). ⑥(실적·통관 생존 취소 가드)은 그 표가 생기는 PR-4a가 `transition_shipment`에 더한다 — 3a 구간엔 그 행이 0이라 공백 없음. 총수 핀 30/152/182는 `test_doc_machines`가 고정한다. 식별자 최장 49자. 이벤트는 커널 단일 통로(`shipments.shipment.created`·`status_changed`)이고 payload에 §2.7의 구분·원천(`shipment_kind`·`so_id`·`po_id`)을 `KIND_PAYLOAD_COLUMNS`로 선적 이벤트에만 싣는다(금액·원가 0).

**부기(2026-10-04 — S3-2 PR-4a 이행: 통관 표·⑥ 생존 취소 가드·M15)** — ②의 `customs_records`를 **M15 `281da4794717`(down `acd34f28c11e`)**로 만들었다: 선적 1:N 신고 사실(`declaration_kind` EXPORT·IMPORT·`declaration_no` VARCHAR(40)·`declared_on`·`accepted_on`[NULL = 미수리]·관세사 FK·메모) — 세율·과세가격·세액·HS 열 0(생성·정정 스키마에도 필드 없음, `extra="forbid"`). (구분, 신고번호) 살아 있는 행 유일(409 `SHIPMENTS.CUSTOMS.DECLARATION_DUPLICATE`), CHECK `declaration_no_shape`(비공백·공백/제어문자 0·대문자)·`note_clean`(탭·LF·CR 외 제어문자 0)·`accept_after_declare`(422 `ACCEPT_BEFORE_DECLARE`). 신고번호는 strip 전 원문의 보이지 않는 글자를 거부하고 strip·대문자화 후 내부 공백은 422(자율 확정). 신고 구분 ≠ 선적 구분은 서비스 422 `KIND_MISMATCH`(DB 미강제 — PROGRESS 부채). ⑥은 `transition_shipment`가 `record_transition` 앞에서 판정한다: 살아 있는 통관 기록 → 409 `SHIPMENTS.SHIPMENT.CUSTOMS_RECORD_ALIVE`(`detail.declaration_nos`) → 살아 있는 ETD·BL_ISSUED·ETA 실적 → 409 `ACTUAL_RECORDED`(`detail.milestone_types`) 순(자율 확정). 출고 결속 실적은 RELEASE_ORDERED에서만(PLANNED 422 `ACTUAL_BEFORE_RELEASE`), 실적·통관 쓰기와 취소는 선적 행 `FOR UPDATE`로 직렬화된다(동시 시험 — 매 라운드 정확히 하나 성공, 취소된 선적에 살아 있는 실적·통관 0). 통관 기록 삭제(사유 필수·audit `shipments.customs.deleted`)가 취소 전 탈출로다. M15 downgrade는 신설 5표(soft delete 포함)·SHIPMENT 통신 기록에 행이 1건이라도 있으면 DDL 전에 거부한다(M14 선례). 취소 가드가 보는 상태 집합(`RECORD_EDITABLE_STATES` = 계획·출고지시)은 S4-2가 피킹~종결 엣지를 열 때 재판정한다(인계 계약).

**부기(2026-10-04 — S3-2 PR-4a 적대 검토 반영)** — 통관 기록: 신고번호는 대문자화 **전** 원문을 ASCII `[A-Za-z0-9][A-Za-z0-9/-]*`·40자로 검사(대문자화로 길이가 느는 'ß'·'ﬃ'가 VARCHAR(40) 500을 내던 구멍), CHECK `declaration_no_shape = ^[A-Z0-9][A-Z0-9/-]*$`. 신고일·수리일 2000~2999(CHECK `date_range`), 메모 CHECK는 보이는 글자 1개 이상.

**부기(2026-10-04 — S3-2 PR-5a 이행: 수입 생성 경로 개방)** — 구분 4종 중 **수입(IMPORT) 생성 경로**를 열었다(마이그레이션 0 — M14 CHECK `kind_source`·`import_has_no_amount`·`import_no_price` 그대로): PO 참조 생성(원천 사본 = 통화·고정 환율·결제조건·Incoterms·거래 상대[공급사 — 생성 시 PO 구분별 공급사 유형 재검증, 커널 단일 표 `PO_SUPPLIER_TYPES`]·담당자, 증빙일 = KST 오늘, 자동 당사자 = 송하인[공급사 영문 스냅샷], 수하인[자사]·송하인 직접 지정 422). 3a가 FROZEN으로 막아 둔 수입 라인 추가·수량 수정을 같은 통로(원천 종류별 소비 — SO 잔량/PO 배정 가능량)로 열었다. 수입선적 문서 흐름은 404 그대로(Q-13), 채널입고·샘플무상은 여전히 닫힘(Q-03). 역순 취소: 살아 있는 수입선적이 있는 PO 취소 = 409 SUCCESSOR_ALIVE(실 테이블 시험으로 대역 교체). 통관 신고 구분 = 선적 구분은 여전히 서비스 422만(DB 강제는 교차 표 — 마이그레이션이 필요해 부채 R-5a-2로 이월, PR-4a R-4a-4 재판정).

**부기(2026-10-05 — S3-3 계획)** — (자율 확정 — 사후 번복 가능. 위 원문 결정은 고치지 않는다.) **선적 커널 위에 서는 S3-3 서류·채권**: ① 선적 당사자 **SHIPPER(자사) 자리 = 자사 레터헤드 불변 판의 as-of 행**(ADR-0092 — 선적 SHIPPER 당사자 422 유지, R-3a-5 종결). ② 사슬 `ChildLink(SHIPMENT→receivables)`(PR-2a)·`ChildLink(SHIPMENT→commercial_invoices)`(PR-5a) — 채권·CI가 살아 있는 선적의 취소 = 409 `SUCCESSOR_ALIVE`. ③ 당사자 추가·삭제가 선적 version+1(R-3a-4 해소 — ADR-0095). ④ 선적 RESERVED 5상태는 여전히 S4-2이고, CI·PL·S/I 발행 게이트(INSPECTED·RELEASED·SHIPPED)가 그 상태들에 걸리므로 운영 발행은 S4-2부터다(ADR-0096). ⑤ 총수: 2b 후 31/151/182 → 5a 후 32/152/184(CI DocKind 편입 — ADR-0095). ⑥ `shipments`에 `UNIQUE(id, so_id)`·`UNIQUE(id, currency, total_amount)`(M16 — 채권 금액 복합 FK 대상, 채권이 살아 있는 동안 선적 총액 UPDATE를 FK가 거부).
