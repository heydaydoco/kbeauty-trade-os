# ADR-0089: `payments` 확장(P-09) — 채권 입금·역기록 대상 분기·이중 입력 의심 409+ack(PI 경로 포함, P-14)·통화 불일치 422 유지·닫힌 PI 입금·역기록 409 유지(P-12)·선수금 초과분 미개방·선수금 FIFO 충당(P-15 채권 항)

- **상태**: 자율 확정 — 사후 번복 가능 (S3-3 계획 2026-10-05 — 오너 지시 2026-09-29에 따라 판정 후보는 더 엄격한(fail-closed) 권장안으로 확정, ADR-0011 부기)
- **날짜**: 2026-10-05
- **관련**: DESIGN.md §7.10(S3-1 부기 ④·⑥ / S3-3 [M4] 보강 ④·⑥ — 문면 변경) / WBS S3-3 산출물 'payments(부분)'·v1.5 '`payments` 확장(기존 컬럼·CHECK·kind 값 변경 금지)'·검증 A '일부입금 전환' / ADR-0064·0068 / PROGRESS P-09·P-12·P-14·P-15 / docs/plans/s3-3-plan.md · docs/plans/s3-3/design-integrated.md(§9 적대 검토 정정 R-01~R-40 우선) — sB B3·B4·B5, X-19, R-09·R-13·R-20·R-21·R-23 / 구현 **PR-2d**(M16b — 독립 검토·3렌즈)
- **번복 비용 큰 결정(오너 확인 권장 2순위와 한 묶음)**: 채권 항의 선수금 충당(DESIGN §7.10 S3-1 부기 ④ '선수금 미차감' 문면 변경 — 노출 감소 방향)은 ADR-0090 노출 산식과 한 묶음으로 오너 확인을 권장한다. INSERT-only 원장 스키마라 채권 입금 행이 쌓이면 되돌릴 수 없다(높음) — 그래서 독립 PR(2d)·3렌즈로 분리했다.

**맥락** — S3-1 `payments`는 PI 선수금 입금 최소형(`pi_id` NOT NULL)이다. S3-3은 채권 입금(잔금)을 같은 원장에 받아야 하고, WBS는 기존 열·CHECK·kind 값 변경을 금지했다. 이중 입력(P-14)·만료/취소 PI 입금(P-12)·선수금 미차감(P-15)·통화 불일치 입금은 S3-3 재판정 대상이었다.

**결정** — ① **M16b**(`s33_payments_receivable`, PR-2d): `pi_id` NOT NULL 해제 + `receivable_id` FK + CHECK `num_nonnulls(pi_id, receivable_id) = 1` + 역기록 복합 FK 2벌째 + **`(receivable_id, partner_id, received_currency)` → `receivables(id, partner_id, currency)` 3열 복합 FK 확정**(R-23 — `payments.partner_id` 실재) — 기존 열·CHECK·kind 무변경, 번역표 확장. ② 채권 입금(T11) = 부분 허용·초과 422 `EXCEEDS_DUE`, 취소 채권 409 `NOT_OPEN`. ③ 역기록(T12) = **peek → 대상 판별 → 거래처 잠금 → 대상별 잠금**(채권 분기는 `lock_chain` 금지·`lock_document`). ④ **PI 입금(T13)도 거래처 잠금 선행**(R-20 — 같은 송금의 채권·PI 교차 경합 차단). ⑤ **이중 입력 의심**(같은 거래처·금액·입금일 근접) = 409 `PAYMENTS.PAYMENT.POSSIBLE_DUPLICATE`(`detail.candidates` — 금액 0) + 후보를 정확히 덮는 `acknowledge_duplicates` ack 재요청만 통과, **채권·PI 양 경로**(PR-2d가 `pi-payments-panel.tsx` 최소 확인 블록 동반). ⑥ **통화 불일치 입금 422 유지**(P-22 — 환율 원천 없음). ⑦ **EXPIRED/CANCELLED PI 입금·역기록 409 유지**(P-12·R-13 — 닫힌 PI엔 살아 있는 SO가 없어 충당과 무관, 정정 경로 부재는 B-02 합류, S3-1 PR-10a 판정 후보 ① 종결). ⑧ **선수금 초과분 = 미개방**(PI 초과 입금 422 유지 — WBS 대비 ⑩, R-09). ⑨ **선수금 충당 = 같은 SO PI 순입금의 id 오름차순 FIFO**를 채권 항에만(P-15 채권 항 종결, SO 항 미차감 유지 — B-04), 종결 SO의 미충당 선수금 > 0은 검산 잡 ADMIN 알림(R-29 — B-02 감지 트리거).

**근거** — 입금은 INSERT-only 원장 하나로 두고 대상만 넓혀야 역기록·검산·감사가 재구현 없이 승계된다. 통화·거래처를 DB 복합 FK로 묶으면 다른 거래처 채권에 입금이 붙는 사고가 구조적으로 0이다. 초과 현금의 귀속(다음 SO 선수금·환불·채권)은 사람 판단이고 받은 뒤 정정할 경로가 없으므로 지금은 받지 않는 쪽이 엄격하다. 채권 항 충당은 현금 사실(입금 행)에만 근거해 노출을 줄인다 — 문면(미차감)대로면 완납 채권의 선수금 몫이 영구 잔존해 운영이 정지한다(R-02).

**기각한 대안** — 별도 `receivable_payments` 표(원장 이원화·역기록 재구현), 2열 FK로 축소(거래처 강제 상실 — 실측으로 기각), 초과분 수용 후 미배정 잔액(귀속 판단 자동화), 통화 불일치 입금 자동 환산(환율 원천 없음), 닫힌 PI 입금 수용(살아 있는 SO 없음 — 귀속 대상 없음), 이중 입력 경고만(조용한 통과), SO 항까지 선수금 차감(과소 방향 — B-04로 이월).

**되돌리기 비용** — **높음** — INSERT-only 원장 스키마(채권 입금 행이 쌓이면 되돌릴 수 없다). 이중 입력 창·충당 순서는 낮음(함수 1곳). 그래서 PR-2d 첫 커밋에 MATCH SIMPLE·3열 복합 FK 시험을 둔다.
