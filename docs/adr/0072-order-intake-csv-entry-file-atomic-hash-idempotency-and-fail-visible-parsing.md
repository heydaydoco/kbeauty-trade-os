# ADR-0072: 오더 인테이크 CSV 입구 — 파일 전체 원자·파일 해시 멱등(advisory lock+부분 유니크)·추측 없는 파싱·중복 PO 응답 계약

- **상태**: 자율 확정(2026-10-03) — 사후 번복 가능 (S3-1 PR-14a). **적대 검토 2차(2026-10-03) 반영 — 판정 후보는 오너 지시로 더 엄격한(fail-closed) 쪽으로 자율 확정**
- **날짜**: 2026-10-03
- **관련**: DESIGN.md §7.4·§12.1·§12.2·§17.1·§17.4 / ADR-09·0027·0041·0053·0059·0071 / docs/plans/s3-1/design-D.md D1-b·D2·D7, design-integrated.md §3.1 PR-14·X-40

**맥락** — 바이어 PO를 CSV 표준 양식으로 대량 접수하는 입구가 필요하다(design-D D2). 부분 성공을 허용하면 수정본 재업로드의 sha256이 달라 이미 착지된 PO가 중복으로 충돌하고, 어느 행이 들어갔는지 운영자가 추적해야 한다. 엑셀 CSV는 날짜 서식·천단위 콤마·지수 표기·오류 값(`#N/A`)·CP949 저장의 '?' 치환·불가시 문자·조합형 글자로 값이 조용히 바뀌는 일이 흔하다. 설계 침묵·충돌: ① 중복 PO의 응답(설계 D2는 422 리포트에 포함, D4·X-40·오케스트레이터 지시는 13a와 같은 409) ② 같은 파일 동시 업로드의 결정성 ③ 양식 다운로드 역할(설계 D7 "CSV=전 역할" / 지시 "전 쓰기 역할") ④ 날짜 빈 칸.

**결정** — ① **파일 전체 원자**: 셀·구조·마스터(바이어·시장 — 형식을 통과한 **모든 행**)·중복 PO·중복 품번/SKU 오류를 **전부 모아** 하나라도 있으면 착지 0건, 없으면 PO 그룹마다 `register_intake`(source_kind=CSV, 착지 단일 통로)를 **한 트랜잭션**에서 부른다. 착지 통로 재검사의 입력 422(KST 자정 경계)도 그 행의 리포트로 번역한다. 50,000행 상한은 **행 객체를 만들기 전 저장 없는 계수 패스**(strict 리더)에서 건다. ② **응답 계약**: 리포트 모양 `detail.errors[{row_no, column, code, message_ko}]`(상한 200 — **중복 PO·마스터 오류를 먼저 채움**)+`total_errors`·`omitted_errors`·`counts_by_code` — 다른 오류가 섞이면 422 `ORDER_INTAKE.FILE.INVALID_ROWS`, **중복 PO만 있으면 13a와 같은 409 `DUPLICATE_BUYER_PO`**. 착지 통로 경합의 같은 409는 13a 모양(`{intake_id|doc_number, status}`)이라 소비자는 `errors` 키 유무로 먼저 분기한다. ③ **파일 해시 멱등**: sha256(원문 바이트) advisory xact lock(LOCK_ORDER (−1), 트랜잭션 첫 문장)으로 같은 파일 업로드를 직렬화 → 멱등 claim → PENDING 같은 sha 선조회 409 `FILE.DUPLICATE` → DB 부분 유니크 위반도 제약명으로 같은 409. 앞 트랜잭션이 **lock_timeout(5s) 이내**에 끝나면 결정적(같은 키=재생·다른 키=`FILE.DUPLICATE`), 넘기면 409 `LOCK_BUSY`(같은 키로 재시도 — 키 미소비). ④ **교착 방지 범위**: 이 입구의 행 잠금은 `(거래처, PO키)` 정렬 착지(인테이크 INSERT의 유니크 대기·거래처 KEY SHARE)뿐이고, 임포트 확정의 다중 행 FOR UPDATE는 id 오름차순(`imports.registry`)이다 — 그 밖의 경로는 전역 LOCK_ORDER가 맡는다. ⑤ **추측 없는 파싱**(fail-visible): strip 전 원문 200자·가장자리 Cc/Cf 거부·ISO 날짜만(시간 붙은 값은 전용 문구)·정수 수량(천단위 첫 그룹 [1-9])·단가는 통화 최소단위 이내(반올림 없음, core `parse_minor_amount`도 '0,500' 거부)·코드 열 지수 표기·엑셀 오류 값·CP949 파일의 '?'·NFC 아님·값 안의 불가시 문자·같은 PO의 헤더 값 불일치(원문)·같은 PO 안 같은 품번/같은 SKU 다른 품번·PO 합계 상한·깨진 따옴표(물리 줄 번호)는 전부 오류. 통화·시장은 ASCII 확인 후 대문자화, 바이어코드·품번·PO번호는 원문. 오류 메시지는 수량·단가 셀 원문을 싣지 않는다(D7). ⑥ **판정 후보 자율 확정(엄격 쪽)**: 양식 다운로드 = TRADE+ADMIN만, PO일자·요청납기일 **필수**, 다른 품번→같은 SKU 거부, PO 원문 표기 차이 거부, PO일자 하한 2000-01-01, 409/422 합성 계약 유지. ⑦ 원본 바이트는 보관하지 않고(스냅샷 = 행마다 9열 원본 셀+파일명+sha) `.xlsx`는 확장자·시그니처로 거부.

**근거** — 전부-또는-전무가 재업로드 충돌과 추적 비용을 없앤다. advisory lock은 "어느 유니크가 먼저 걸리나"를 없애 같은 파일 동시 업로드의 응답을 결정적으로 만든다(직렬화 범위는 같은 sha뿐). 계수 패스는 짧은 행 수백만 줄 파일로 메모리를 소진시키는 경로를 닫는다(300만 줄 tracemalloc 피크 64MiB 이내 시험). 추측 보정은 바이어가 낸 값과 다른 수주를 만들므로 거부하고 고치게 한다.

**기각한 대안** — 부분 성공, 중복 PO도 항상 422(13a 409 계약과 갈라짐), 항상 409 먼저(두 번에 나눠 고침), 파일 유니크만으로 직렬화(비결정), 헤더 끝 빈 열 자동 절단·NFD 자동 정규화·엑셀 일련번호 해석(추측), 단가 반올림, `.xlsx` 수용(신규 의존·D-D2 트리거 대기), 원본 파일 `documents` 보관(소비자 S6-1 부재 — ADR-0041), 양식 전 역할 공개·날짜 선택 입력(판정 후보 — 엄격 쪽 채택).

**되돌리기 비용** — 낮음. 입구는 착지 함수 위 어댑터(서비스 1곳·파서 1곳), 응답 계약 변경은 `_report` 1곳+프런트(14b), 양식 열 추가는 `csv_template` 상수+`PARSER_VERSION`, 역할·필수 여부는 라우트 게이트·파서 1곳.
