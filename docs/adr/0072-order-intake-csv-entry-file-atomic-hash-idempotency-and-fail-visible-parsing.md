# ADR-0072: 오더 인테이크 CSV 입구 — 파일 전체 원자·파일 해시 멱등(advisory lock+부분 유니크)·추측 없는 파싱·중복 PO 응답 계약

- **상태**: 자율 확정(2026-10-03) — 사후 번복 가능 (S3-1 PR-14a)
- **날짜**: 2026-10-03
- **관련**: DESIGN.md §7.4·§12.1·§12.2·§17.1·§17.4 / ADR-09·0027·0041·0053·0071 / docs/plans/s3-1/design-D.md D1-b·D2·D7, design-integrated.md §3.1 PR-14·X-40

**맥락** — 바이어 PO를 CSV 표준 양식으로 대량 접수하는 입구가 필요하다(design-D D2). 부분 성공을 허용하면 수정본 재업로드의 sha256이 달라 이미 착지된 PO가 중복으로 충돌하고, 어느 행이 들어갔는지 운영자가 추적해야 한다. 엑셀 CSV는 날짜 서식·천단위 콤마·지수 표기·불가시 문자로 값이 조용히 바뀌는 일이 흔하다. 설계 침묵·충돌: ① 중복 PO의 응답(설계 D2는 422 리포트에 포함, D4·X-40·오케스트레이터 지시는 13a와 같은 409) ② 같은 파일 동시 업로드의 결정성(부분 유니크만으로는 PO 유니크와 파일 유니크 중 어느 쪽이 먼저 걸릴지 정해지지 않는다) ③ 양식 다운로드 역할(설계 D7 "CSV=전 역할" / 지시 "전 쓰기 역할").

**결정** — ① **파일 전체 원자**: 셀·구조·마스터(바이어·시장)·중복 PO·중복 품번/SKU 오류를 **전부 모아** 하나라도 있으면 착지 0건, 없으면 PO 그룹마다 `register_intake`(source_kind=CSV, 착지 단일 통로 — CSV 모듈은 `OrderIntake`를 만들지 않는다)를 **한 트랜잭션**에서 부른다. ② **응답 계약**: 오류 리포트 모양은 하나(`detail.errors[{row_no, column, code, message_ko}]` 최대 200+`total_errors`·`omitted_errors`) — 다른 오류가 섞이면 422 `ORDER_INTAKE.FILE.INVALID_ROWS`(중복 PO 행 포함), **중복 PO만 있으면 13a와 같은 409 `TRADE_DOCS.DOCUMENT.DUPLICATE_BUYER_PO`**(한 번에 다 고칠 수 있게 하면서 13a 계약을 지킨다). ③ **파일 해시 멱등**: sha256(업로드 원문 바이트) **advisory xact lock**으로 같은 파일 업로드를 직렬화 → 멱등 claim(같은 키=최초 결과 재생) → PENDING 같은 sha 선조회 409 `FILE.DUPLICATE`(기존 id 목록) → DB 부분 유니크(sha, 그룹 키) 위반도 제약명으로 같은 409. 확정·거부 후 재업로드는 허용되고 PO 중복 검사가 수렴시킨다. 착지는 `(바이어, PO키)` 정렬 순(동시 파일 간 교착 방지). ④ **추측 없는 파싱**(fail-visible): ISO 날짜만·정수 수량(천단위 콤마는 3자리 그룹 위치만)·단가는 통화 최소단위 이내만(반올림 없음)·코드 열 지수 표기·값 안의 불가시/제어 문자·같은 PO의 헤더 값 불일치(PO 원문 표기 차이 포함)·같은 PO 안 같은 품번/같은 SKU 다른 품번·PO 합계 상한 초과는 전부 행 오류. 통화·시장 코드만 대문자화, 바이어코드·품번·PO번호는 원문(대소문자 다른 바이어코드는 힌트만). ⑤ 원본 바이트는 보관하지 않고(`extracted_snapshot`=원본 셀 문자열+파일명+sha) `.xlsx`는 확장자·시그니처로 거부, 양식 다운로드는 설계대로 전 역할(헤더뿐).

**근거** — 전부-또는-전무가 재업로드 충돌과 추적 비용을 없앤다. advisory lock은 "어느 유니크가 먼저 걸리나"를 없애 같은 파일 동시 업로드의 응답을 결정적으로 만든다(직렬화 범위는 같은 sha뿐이라 다른 파일 처리량에 영향 없음). 추측 보정은 바이어가 낸 값과 다른 수주를 만들므로 거부하고 고치게 한다.

**기각한 대안** — 부분 성공(유효 PO만 착지), 중복 PO도 항상 422(13a 409 계약과 갈라짐), 항상 409 먼저(형식·중복을 두 번에 나눠 고치게 함), 파일 유니크만으로 직렬화(코드가 비결정), 엑셀 일련번호·`10/5/2026` 해석(월/일 모호), 단가 반올림, `.xlsx` 수용(신규 의존·D-D2 트리거 대기), 원본 파일 `documents` 보관(소비자 S6-1 부재 — ADR-0041).

**되돌리기 비용** — 낮음. 입구는 착지 함수 위 어댑터(서비스 1곳·파서 1곳), 응답 계약 변경은 `_report` 1곳+프런트(14b), 양식 열 추가는 `csv_template` 상수+`PARSER_VERSION`.
