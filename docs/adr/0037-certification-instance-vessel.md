# ADR-0037: 인증 인스턴스 — 폴리모픽 대상·스냅샷 동결·활성 한정 유니크

- **상태**: 채택 (S2-2 계획 웹 세션 판정 2026-08-11 — 안건 ①·②)
- **날짜**: 2026-08-11
- **관련**: DESIGN.md §5.1·[M2] 보강(S2-2 PR-1) ① / ADR-0028(폴리모픽 선례)·0033("그때 요건" 동결 예약) / s2-2-plan.md §2

**맥락** — §5.1 "certifications(대상×템플릿 인스턴스)"의 대상 축은 적용단위 5종(처방/SKU/시설/기업/성분)을 수용해야 하고(§6.5 인증수출자·§9 ③ 기업 단위 요건이 소비 예약), 템플릿은 개정되는 마스터라 "그때 요건"의 동결이 필요하다(ADR-0033 예약).

**결정** — 대상=폴리모픽(target_type 5값+target_id, 실 FK 없음·서비스 존재 검증. FACILITY→partners는 **잠정** — 복수 공장 실수요 또는 S3-1 OEM 계획 보고 시 facilities 마스터 재판정, COMPANY=자사 단일·target_id NULL). 생성=CONFIRMED 템플릿 한정+요건 정의 7필드 스냅샷(estimated_cost는 명시 예외 — 실비 S3-4·예상비 최신값 템플릿 참조)+체크리스트→태스크 참조 복사(ADR-05). 유니크=활성 한정(종결 2태 제외·만료 포함 — 재도전=신규 인스턴스, 만료 후 재개=기존 행 경유 단일화. COMPANY 전용 부분 유니크 분리 — PG NULL 구별).

**근거** — 폴리모픽은 documents 선례(ADR-0028)와 동형이고, 스냅샷 예외 명시가 판정자의 오독(비용 동결 승인으로 읽힘)을 막으며, 활성 한정 유니크가 재도전·재개 경로를 구조로 단일화한다.

**기각한 대안** — 대상별 nullable FK 5컬럼+CHECK(스키마 비대·선례 이탈), facilities 마스터 즉시 신설(반입 이월 상태에서 과잉 — 재매핑 비용 0인 지금은 잠정이 싸다), estimated_cost 스냅샷 포함(중복 보관 — §10.1과 이원화).

**되돌리기 비용** — 중간. 유니크 술어 변경은 마이그레이션 1건이나, S2-3 매트릭스가 이 대상 축·스냅샷을 소비하기 시작하면 재매핑 비용이 커진다(FACILITY 재판정 트리거를 관찰 원장에 등재).

**부기(2026-09-30 — S3-1 계획)** — (자율 확정 — 사후 번복 가능. 위 원문 결정은 고치지 않는다.) **OEM 슬롯·facilities 재판정 소진.** S3-1 PO는 시설을 참조하지 않는다(`supplier_partner_id`+`po_kind`) — facilities 마스터를 신설하지 않고 이 ADR의 FACILITY→partners 잠정 매핑을 유지한다. OEM 생산 발주의 구분 슬롯은 `purchase_orders.po_kind`(`PURCHASE`·`OEM_PRODUCTION`)로 완결하고 마일스톤 프로파일 적용은 S3-2 몫이다. **재판정 트리거(먼저 도달)**: (a) S3-2 OEM 마일스톤 프로파일 계획 보고에서 시설 단위 일정이 필요하다고 판정될 때 (b) 한 거래처의 두 번째 시설 인스턴스 등록 시도 (c) 시설 인증 인스턴스 대량 등록 착수 전 — 그 이후는 재매핑 비용>0이다. 근거: ADR-0057 / design-F.md F3·F7.

**부기(2026-10-04 — S3-2 계획)** — (자율 확정 — 사후 번복 가능. 위 원문 결정은 고치지 않는다.) **OEM 마일스톤 프로파일 판정 결과**: 위 부기의 "마일스톤 프로파일 적용은 S3-2 몫"은 **`profile_id`·프로파일 마스터 미신설**로 판정했다 — OEM 생산 마일스톤은 `milestones`의 PO 소유 행(코드 고정 4종 ⇔ `po_kind='OEM_PRODUCTION'`)이다. 재판정 트리거 **(a) "시설 단위 일정 필요"는 불발동**(4단계 일정은 PO=거래처 1곳 단위로 충분)이며 facilities 미신설·FACILITY→partners 잠정 매핑을 유지한다. 트리거 (b)·(c)는 그대로 유지한다. 근거: ADR-0085 / design-B.md B15.
