# ADR-0098: S3-3 권한·마스킹 — AUTHZ 행(경로 단위)·`GOVERNED_PREFIXES` +6(documents 통제 편입)·documents 전표 첨부 A·T(삭제 포함)·생성물 다운로드 축소·계좌번호 마스킹·원가 채널 0·렌더 주입·원격 로드 차단

- **상태**: 자율 확정 — 사후 번복 가능 (S3-3 계획 2026-10-05 — 오너 지시 2026-09-29에 따라 판정 후보는 더 엄격한(fail-closed) 권장안으로 확정, ADR-0011 부기)

- **관련**: DESIGN.md §2·§18.1·§4.7(S3-3 [M4] 보강) / ADR-0024·0028·0029·0067·0079 / PROGRESS C-D1(부채) / docs/plans/s3-3-plan.md · docs/plans/s3-3/design-integrated.md(§9 적대 검토 정정 R-01~R-40 우선) — sC C6·C7, sA §A13·§A16, X-03·X-08·X-11·X-23·X-27, R-11·R-12·R-17·R-18·R-28 / 구현 PR-2a·3a·3b·4a·5a·5b

**맥락** — S3-3은 청구·대금·서류·L/C 쓰기와 계좌번호가 담긴 대외 전달물을 연다. documents는 통제 접두어 밖이었고(현행 매트릭스에 없음), 전표 소유가 열리면서 같은 경로의 권한 의미가 바뀐다. 기존 `CAN_MANAGE=(TRADE, CERT)`로 DELETE가 열려 있어 인증 역할이 전표 첨부를 지울 수 있다(R-18).

**결정** — ① 권한 표 = 통합 §2.9(경로 단위, 좁은 쪽): 채권 발생·입금·역기록·short-close·QT·PI 렌더·CI 발행·재발행·취소·L/C 쓰기 = A·T / CI 미리보기·렌더 재시도·FREE PATCH·S/I·CI·PL·S/I 생성물 다운로드 = A·T·L / OPENING·채권 취소·플래그·레터헤드 = A / 조회 전 역할. ② **`GOVERNED_PREFIXES` +6**: `/api/v1/company-profiles`·`/commercial-invoices`·`/shipping-instructions`·`/receivables`·`/feature-flags`·`/documents`(기존 documents 행 전부를 실측 역할 그대로 등재). ③ **documents**: 전표 6종 소유 업로드·링크 = A·T(CERT 403을 404보다 먼저), **전표 소유 삭제 = A·T**(404 → 403 → 409 — 삭제는 본문에 owner_type이 없어 404가 먼저), 생성물 삭제 409(역할 무관), 업로드·링크 스키마 `owner_type` 길이 = 열 길이 상수(R-11), 쓰기 스키마 전부 forbid(P-50 documents 몫 종결 — R-12). 기존 SKU·LABEL·CERTIFICATION·COMM_LOG 소유는 무변경. ④ **계좌번호**: CI 상세 `account_no` A·T·L만(C·V 끝 4자리 외 마스킹), CI 미리보기 계좌 후보·요약 A·T만(L = 출처만), 목록·CSV 계좌번호 열 0, 로그·audit·outbox에 계좌번호 0. PI 상세의 기존 전 역할 노출은 부채 C-D1(새 채널은 처음부터 좁힌다). ⑤ **원가 채널 0**: PO·수입선적 소유 첨부·수입선적 서류·PO 발주서 렌더 미개방, 렌더 뷰 허용 필드 고정(원가 키·`internal_note`·담당자·감사 행위자 0 — R-28) — ADR-0024의 10번째 채널을 열지 않는다. ⑥ 렌더 주입 방어·원격 리소스 로드 차단은 ADR-0093. ⑦ 판정 순서 401 → 403 → 404 → 409 → 422, 부모-자식 경로 불일치 404·부작용 0, 본문 소속 불일치 422.

**근거** — 매트릭스가 모르는 분기는 회귀 시험이 없다(통제 접두어 편입). 새 민감 채널은 처음부터 좁히고, 넓히는 쪽은 행 1줄이라 낮은 비용으로 되돌릴 수 있다.

**기각한 대안** — documents를 통제 접두어 밖에 유지(전표 첨부·생성물 축소의 회귀 시험 부재), 전표 첨부 물류 쓰기(X-11 — 부채 C-D6 트리거), CI 상세 계좌번호 전 역할(X-27), PI 기존 노출 동시 수정(범위 밖 — C-D1), 원가 열람 역할에 PO 첨부 개방(원가 채널).

**되돌리기 비용** — **낮음** — 넓히기는 행 1줄. 좁히기는 중간(이미 쓰는 사용자 흐름).
