**맥락** — S3-1 PR-16이 남긴 부채: ③ 사용자 역할 변경 화면 부재(CLI는 관리자만 만들고 역할 변경은 API뿐 — S3-2는 물류 계정이 처음 필요) ⑤ SearchSelect 빠른 입력 오선택 ⑦ 실브라우저 워크스루 스크립트 리포 미보존(브라우저 e2e 도구 채택 판정 — 의존성 추가 금지).

**결정** — ① **브라우저 e2e 도구 미채택** — `@playwright/test`·Python `playwright` 의존성·CI 브라우저 잡 추가 0. 렌즈 11 증거는 3층: (i) 반복 가능한 실 HTTP e2e `tests/e2e/test_s3_2_walkthrough.py`(SO 확정→부분선적 2건→선적중→롤오버+통보→ETA 휴일 경고/UNVERIFIED→통관 수리→적재기한→재계산→취소 2단 복귀) (ii) 소스 계약 vitest(390px·날짜 문자열 `new Date` 금지·라벨 단일 표·알림 이동 표) (iii) 리포 밖 실브라우저 관통 1회(기존 venv playwright·`/opt/pw-browsers/chromium` — 단계·`scrollWidth`·결함을 PROGRESS 본문에 기록). 부채 ⑦ 유지·트리거 갱신: 실브라우저 전용 회귀 2 PR 연속 또는 P4 착수. ② **사용자·역할 화면 `/settings/users`**(ADMIN, 백엔드 0 — 기존 API 소비, 마지막 관리자 오류 안내) — 병합 순서를 PR-3a 앞(2b 다음)으로. 계정은 **CLI 생성 → 화면 역할 부여 → ADMIN 회수**, 계정 생성 화면·API 미신설(부채 — 트리거: 운영 개시 후 개설 2건↑ 또는 요청). ③ **SearchSelect 오선택 수정**(PR-3b — 새 소비처가 생기므로).

**근거** — 렌즈 11은 '1회 관통'을 요구하지 도구를 요구하지 않는다(§22). 의존성·CI 구성(ADR-0073 샤드) 변경은 되돌리기가 비싸다. 역할 화면을 3a 앞에 두면 물류 역할 실기동 관통(3b·4b)에서 API 직접 호출이 0이 된다.

**기각한 대안** — `@playwright/test`+CI 잡(캐시·시간·공급망 표면), 스크립트를 리포에 두고 실행 안 함(실행되지 않는 테스트는 증거가 아님), 계정 생성 화면 동반(범위 확대·비밀번호 전달 경로 설계 필요), 역할 화면을 P6로 이월(물류 계정 운영 개시 불가).

**되돌리기 비용** — 낮음(도구 채택은 나중에 ADR+의존성+CI 잡 가산, 지금 채택 후 걷어내는 쪽이 비싸다 / 화면은 프런트만).

**부기(2026-10-04 — S3-2 PR-7 이행, 결정 ②)** — (위 원문 결정은 고치지 않는다.) `/settings/users`(ADMIN 전용) 신설 — **백엔드 변경 0**(`git diff --stat f7ceaf7 -- backend` 빈 출력). 기존 API만 소비: `GET /users`(Page 50 — 검색 파라미터가 API에 없어 검색 UI 없음)·`POST /users/{id}/roles`·`DELETE /users/{id}/roles/{role}`(200+UserSummary)·`PATCH /users/{id}/active`·`POST /users/{id}/unlock`. 모든 변경은 확인 대화상자(대상 이메일·변경 내용), 본인 ADMIN 회수·본인 비활성화는 경고문, `IDENTITY.ADMIN.LAST_ONE`(409)은 서버 문구 그대로 대화상자 안에 남긴다. 멱등 키 = 대화상자 1회 열림당 1개(재시도 같은 키). 셸 ADMIN 메뉴 "사용자·역할", 비ADMIN은 메뉴 미노출·직접 진입 시 권한 안내(목록 호출 0). 화면에 "계정 생성은 관리자 CLI" 안내 1줄 — 계정 생성 화면·API 미신설 그대로. 감사는 기존 `identity.role.granted/revoked`·`identity.admin.last_one_protected`가 남음을 실기동 DB로 확인(sC C7). C7 실측: API에 **"자기 자신 ADMIN 회수 금지" 가드는 없다**(마지막 활성 관리자 보호만) — 화면 경고로만 다루고 가드 신설은 하지 않았다(부채 R-7-1). 렌즈 11 (iii) 리포 밖 실브라우저 관통 1회(R-22 경로 CLI 생성 → 화면 '물류' 부여 → ADMIN 회수 → 마지막 관리자 409 → 물류 계정 메뉴 미노출·직접 진입 안내, 390px `scrollWidth` 390)은 PROGRESS 'S3-2 PR-7'.

**부기(2026-10-04 — S3-2 PR-3b 이행, 결정 ③·① iii)** — (위 원문 결정은 고치지 않는다.) **SearchSelect 오선택 수정**: 원인 = 입력 직후~디바운스(300ms) 만료 전에는 쿼리 키가 옛 검색어라 그 결과가 목록으로 그려져 클릭·Enter가 받았다. 결과가 **현재 입력어의 응답일 때만** 목록을 그리고(대기·요청 중 "검색 중…"), 클릭·Enter 처리 시점에도 최신 입력어(ref)와 결과 검색어를 다시 대조한다(`frontend/src/components/search-select.tsx` — 공용 컴포넌트 1곳, 기존 소비처 8곳 회귀 0). vitest "빠른 입력 직후 클릭·Enter 선택 0" 2건(원복 변이에서 실패 확인). 리포 밖 실브라우저 실측: 검색 전 목록 [알파물류, 빠른화물] → 80ms 안에 "Fast" 입력 직후 그 콤보박스 목록의 옵션 0·"검색 중…" 1·이른 Enter 선택 0 → 디바운스 뒤 [빠른화물]만. 렌즈 11 (iii) 선적 화면 관통 1회와 발견 결함 2건(409 뒤 잔량 표시 엇갈림·390px 품명 글자 단위 꺾임 — 둘 다 수정)은 PROGRESS 'S3-2 PR-3b'.
