# ADR-0086: 브라우저 e2e 도구 미채택·렌즈 11 3층 증거·사용자 역할 화면 S3-2 배정(계정 생성 API 미신설)·SearchSelect 오선택 수정

- **상태**: 자율 확정 — 사후 번복 가능 (S3-2 계획 2026-10-04 — 오너 지시 2026-09-29에 따라 판정 후보는 더 엄격한(fail-closed) 권장안으로 확정, ADR-0011 부기)
- **날짜**: 2026-10-04
- **관련**: DESIGN.md §2·§14·§22 렌즈 11(S3-2 [M4] 보강) / ADR-0073 / PROGRESS S3-1 PR-16 부채 ③⑤⑦ / docs/plans/s3-2-plan.md · docs/plans/s3-2/design-integrated.md(§9 적대 검토 정정 우선) — sD §D14~D16, sC §C7, R-22 / 구현 PR-3b(SearchSelect)·PR-7(역할 화면)·PR-8(워크스루)

**맥락** — S3-1 PR-16이 남긴 부채: ③ 사용자 역할 변경 화면 부재(CLI는 관리자만 만들고 역할 변경은 API뿐 — S3-2는 물류 계정이 처음 필요) ⑤ SearchSelect 빠른 입력 오선택 ⑦ 실브라우저 워크스루 스크립트 리포 미보존(브라우저 e2e 도구 채택 판정 — 의존성 추가 금지).

**결정** — ① **브라우저 e2e 도구 미채택** — `@playwright/test`·Python `playwright` 의존성·CI 브라우저 잡 추가 0. 렌즈 11 증거는 3층: (i) 반복 가능한 실 HTTP e2e `tests/e2e/test_s3_2_walkthrough.py`(SO 확정→부분선적 2건→선적중→롤오버+통보→ETA 휴일 경고/UNVERIFIED→통관 수리→적재기한→재계산→취소 2단 복귀) (ii) 소스 계약 vitest(390px·날짜 문자열 `new Date` 금지·라벨 단일 표·알림 이동 표) (iii) 리포 밖 실브라우저 관통 1회(기존 venv playwright·`/opt/pw-browsers/chromium` — 단계·`scrollWidth`·결함을 PROGRESS 본문에 기록). 부채 ⑦ 유지·트리거 갱신: 실브라우저 전용 회귀 2 PR 연속 또는 P4 착수. ② **사용자·역할 화면 `/settings/users`**(ADMIN, 백엔드 0 — 기존 API 소비, 마지막 관리자 오류 안내) — 병합 순서를 PR-3a 앞(2b 다음)으로. 계정은 **CLI 생성 → 화면 역할 부여 → ADMIN 회수**, 계정 생성 화면·API 미신설(부채 — 트리거: 운영 개시 후 개설 2건↑ 또는 요청). ③ **SearchSelect 오선택 수정**(PR-3b — 새 소비처가 생기므로).

**근거** — 렌즈 11은 '1회 관통'을 요구하지 도구를 요구하지 않는다(§22). 의존성·CI 구성(ADR-0073 샤드) 변경은 되돌리기가 비싸다. 역할 화면을 3a 앞에 두면 물류 역할 실기동 관통(3b·4b)에서 API 직접 호출이 0이 된다.

**기각한 대안** — `@playwright/test`+CI 잡(캐시·시간·공급망 표면), 스크립트를 리포에 두고 실행 안 함(실행되지 않는 테스트는 증거가 아님), 계정 생성 화면 동반(범위 확대·비밀번호 전달 경로 설계 필요), 역할 화면을 P6로 이월(물류 계정 운영 개시 불가).

**되돌리기 비용** — 낮음(도구 채택은 나중에 ADR+의존성+CI 잡 가산, 지금 채택 후 걷어내는 쪽이 비싸다 / 화면은 프런트만).
