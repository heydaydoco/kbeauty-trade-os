# ADR-0099: S3-3 화면 계약 — 서버 `allowed_actions`(S3-3 신규 동작만 — 부분 도입)·서류 파일 단일 다운로드 통로·CI 작성 전용 화면·멱등 키 화면 수준 보존(`useIdempotencyKeys`)·목록 파생 필터 금지·aging 기준일 서버 고정·CI 목록 메뉴 S4-2

- **상태**: 자율 확정 — 사후 번복 가능 (S3-3 계획 2026-10-05 — 오너 지시 2026-09-29에 따라 판정 후보는 더 엄격한(fail-closed) 권장안으로 확정, ADR-0011 부기)
- **날짜**: 2026-10-05
- **관련**: DESIGN.md §14·§18.4(S3-3 [M4] 보강) / ADR-0066·0086 / PROGRESS R-3b-9·R-4b-4·R-8-2·R-6-4·PR-16 ⑧ / docs/plans/s3-3-plan.md · docs/plans/s3-3/design-integrated.md(§9 적대 검토 정정 R-01~R-40 우선) — sD D1·D4·D6·D9·D11·D17·D19·D20, X-28·X-33·X-34, R-01·R-07·R-17·R-20·R-29 / 구현 PR-2c·3c·4b·5c(+PR-2d PI 패널 최소 확인 블록·PR-6 라벨 대사)

**맥락** — S3-3은 화면 9종 이상을 연다. S3-1·S3-2 화면은 버튼 표시를 클라이언트가 상태로 판정해 규칙이 둘로 갈릴 위험이 있었고, '확인 없이 닫기'로 멱등 키를 잃는 결함(R-3b-9·R-4b-4)이 대화상자마다 반복됐다.

**결정** — ① **S3-3이 여는 동작 버튼 = 서버 `allowed_actions`만**(권한 매트릭스와 같은 상수에서 생성 — 대사 K 시험). QT·PI·SO 기존 동작은 부분 도입(부채 D-01). ② **파일 다운로드 통로 하나**(기존 documents 다운로드 — 생성물 역할 축소는 서버가 판정). ③ CI·PL 작성 = 원천 선적 경로의 전용 화면(2단 — 미리보기 → NOTICE 확인 → 발행, 탭 임시 저장·입력 보존·낡은 미리보기 표시, 서버 초안 없음 — 부채 D-06), 운영 게이트 문구 상시 표시. ④ 금액·발행 대화상자의 멱등 키는 **화면 수준 Map**(`useIdempotencyKeys` — 같은 본문 = 같은 키, 닫았다 열어도 유지). ⑤ 목록 필터 = 저장 열만(파생 필터 0 — 부채 D-03), aging 기준일 = 서버 KST 오늘(파라미터 없음 — 부채 D-04), `DUE_UNKNOWN` ≠ 미도래(적색·사유 라벨), 통화 간 합산 0. ⑥ 채권 등록 2단(미리보기에 `will_complete` — 'SO 완료 예정'), 이중 입력 확인 블록(후보 전부 확인 체크 전 저장 비활성 — PR-2d가 PI 패널에 최소형 동반, 2c `PaymentsPanel`이 흡수). ⑦ L/C 화면: tolerance 상·하한 = 서버 문자열, 임박 = 서버 `urgency`(색 + 글자), 체크리스트 근거 빈칸 제출 불가·'적합' 문구 0. ⑧ '미수 미반영' 배지 삭제 + 사유 라벨 `RECEIVABLE_PROVIDER_NOT_REGISTERED`(R-07), SO '초과 입금 의심' 배지(R-29), PI '선수금 입금완료'(PR-16 ⑧), 셸 역할 한국어 라벨(R-8-2), 라벨 대사 4표(R-6-4 — 표가 생기는 PR이 행을 더하고 PR-6이 닫는다). ⑨ **CI 목록 화면·메뉴는 S4-2**(운영 CI 0 구간 — 부채 D-02). ⑩ 한국어 UI·390px 가로 스크롤 0·`new Date` 금지 확장(KST 오늘은 서버값).

**근거** — 버튼 판정을 서버로 모으면 상태·역할 규칙이 한 곳에서만 바뀐다. 멱등 키를 화면 수준에 두면 금액 대화상자를 닫았다 다시 열어도 같은 요청이 중복 생성되지 않는다(R-3b-9 구조 반복 방지).

**기각한 대안** — 클라이언트 상태 판정(규칙 이원화), 서류별 다운로드 엔드포인트(통로 증식 — X-24), CI 작성 모달(입력량·NOTICE 확인 흐름 수용 불가), 컴포넌트 지역 멱등 키(닫기 시 상실), 파생 필터(페이지 `total` 불일치·미수 정의 이원화 — X-28), CI 목록 메뉴 선개방(운영 0건 화면).

**되돌리기 비용** — **낮음** — 화면 계약(백엔드 계약 변경 0). `allowed_actions` 확대는 D-01 트리거로.
